## 阶段 3 — 社区校准

### FAIL（必须修复，4 项）

#### F1. scrollTopBtn 触控尺寸 = 40×40px
- **症状**：返回顶部按钮只有 40×40px
- **根因**：`src/App.css:331` `width: 40px; height: 40px;`
- **标准**：Apple HIG ≥ 44px，本项目 design_guide 明确要求 ≥ 48px
- **证据**：`grep "width: 40px; height: 40px" src/App.css` — 唯一出现
- **影响**：50-60 岁老花眼用户手指精度下降，40px 触控区域太小
- **防护规则**：A-12 检查应捕获此问题（guardrails 尚未覆盖 scrollTopBtn）

#### F2. SPA 路由不使用 pushState
- **症状**：应用使用自定义 viewStack（React state），浏览器前进/后退按钮失效
- **根因**：`App.jsx` 的 `goBack()` 和 `showView()` 全部操作 React state 栈，无任何 `history.pushState` 调用
- **标准**：design_guide.md 明确要求「使用 pushState/history.back()，不是自定义栈」
- **证据**：`grep -rn "pushState\|replaceState" src/` — 零匹配
- **影响**：用户按系统返回键或手势 → 直接退出 App 而非返回上一页
- **对应防护规则**：A-5 → GUARDRAILS.md 已记录但当前代码未修复

#### F3. 13px 字号低于绝对下限
- **症状**：`.conf-badge` 和 `.conf-tooltip` 使用 13px 字号
- **根因**：`src/App.css:209` `font-size: 13px` (conf-badge), line 281 `font-size: 13px` (conf-tooltip)
- **标准**：design_guide.md `--font-caption: 14px` 为"绝对下限"
- **证据**：grep 确认两处 13px
- **影响**：置信度标签是核心交互信息，13px 对老花眼用户阅读困难

#### F4. #777777 文字对比度不达标
- **症状**：`#777` 色值在白色背景上对比度仅 4.48:1
- **根因**：tokens.css 中 `--color-text-muted: #777`，注释声称 4.53:1 但实际测量为 4.48:1
- **标准**：WCAG 2.1 AA 普通文字 ≥ 4.5:1
- **证据**：精确计算 luminance(0.18447)，contrast = 4.48:1
- **影响**：所有 `--color-text-muted` 文字（搜索图标、清除按钮、详情辅助文字）对视觉障碍用户不达标
- **建议修复**：将 `#777` 改为 `#757575`（对比度 4.6:1）或 `#6d6d6d`（4.97:1）

### WARN（建议修复，6 项）

#### W1-W3：硬编码颜色/字号/设计 token
- 多处硬编码 `#005EB8`、`#2e7d32`、`#e8f5e9`、`#e8f0fa`、`#f0f5fb` 等颜色值
- 大量硬编码 px 字号（14px/15px/16px/17px）未使用 `var(--font-*)`
- Tab bar 字号 14px 作为主导航文字偏小

#### W4：tokens.css 被 double-import
- main.jsx 和 App.jsx 均 import tokens.css
- Vite 会去重，无功能影响，仅代码整洁问题

#### W5：data.js 加载失败无提示
- 若 data.js 加载失败，搜索显示 0 结果，用户无法区分

#### W6：build-ios.sh 缺少 pipefail
- xcodebuild 输出通过 grep 过滤，可能隐藏构建失败

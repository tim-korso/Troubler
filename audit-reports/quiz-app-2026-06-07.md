## 阶段 3 — 社区校准

### FAIL（必须修复，6 项）

#### F1. 🚫 user-scalable=no + maximum-scale=1.0
- **症状**：用户完全无法缩放页面
- **根因**：`index.html:8` `<meta name="viewport" content="..., maximum-scale=1.0, user-scalable=no, ...">`
- **标准**：design_guide.md 禁止清单第 1 条 + WCAG 2.1 要求
- **证据**：源码和 dist/ 中均存在
- **影响**：所有用户无法缩放，低视力用户被完全排斥
- **修复**：改为 `maximum-scale=3.0`，移除 `user-scalable=no`

#### F2. 🚫 Emoji 作为图标（全局使用）
- **症状**：导航栏、图标、状态标记均使用 emoji
- **根因**：Header.jsx 使用 🏠📝📊📋🔍，Home.jsx 使用 📚📖，QuestionCard.jsx 使用 ✓✗✅❌⭐ 等
- **标准**：design_guide.md 禁止清单第 3 条「emoji 当图标——用 SVG 或 CSS」
- **证据**：19+ 处 emoji 出现在 JSX 中
- **影响**：跨平台渲染不一致，屏幕阅读器读出 unicode 描述

#### F3. 🚫 0.6875rem (11px) 字号 — 10 处
- **症状**：badge、type tag、font-size button 等使用 0.6875rem
- **根因**：app.css 中 10 处 `font-size: 0.6875rem`
- **标准**：design_guide.md `--font-small: 13px` 绝对下限；在「小」字体模式（root=14px）下 0.6875rem = 9.6px
- **证据**：grep 确认 10 处 0.6875rem
- **影响**：11px 正常视力尚可，9.6px（小字体模式）完全不可读

#### F4. 🚫 0.75rem (12px) 字号 — 21 处
- **症状**：大量辅助文字使用 0.75rem
- **标准**：低于 13px 下限
- **证据**：grep 确认 21 处 0.75rem
- **影响**：在「小」字体模式（root=14px）下 = 10.5px

#### F5. 🚫 题目导航按钮 36×36px
- **症状**：`.q-nav-btn` 为 36×36px
- **根因**：`app.css:781-782`
- **标准**：design_guide.md「最小触控尺寸 44×44px」
- **影响**：手指无法精确点击

#### F6. 🚫 PWA 关闭按钮 28×28px
- **症状**：`.pwa-banner-close` 为 28×28px
- **标准**：触控最小 44×44px
- **影响**：极难点击关闭

### WARN（建议修复，8 项）

#### W1-W3：大面积硬编码颜色
- `#1e3a5f` 使用 10+ 次（标题色），应定义为 CSS 变量
- `#4A90D9`, `#7B68EE`, `#E85D75`, `#E8913A`（类型标签色）未使用变量且部分对比度不达标
- `#b91c1c`, `#15803d`, `#6366f1`, `#bfdbfe`, `#eff6ff`, `#f8faff`, `#fde68a`, `#fef3c7`, `#e0e7ff`, `#3730a3`, `#f1f5f9`, `#f8fafc` 等散落各处
- design_guide 明确禁止「不使用 CSS 变量的硬编码颜色值」

#### W4：颜色对比度问题
- `#94a3b8` on white: 2.6:1 — hover 边框色，影响可辨性
- `#7B68EE` on white: 4.2:1 — 类型标签，白字在紫色背景上需验证
- `#6366f1` on white: 4.5:1 — 刚好卡线

#### W5：quiz-data.json 3.2MB 无加载进度
- 首次加载 20-30 秒，只有 spinner 无进度条

#### W6：CSS 变量命名不匹配 design_guide
- app.css 使用 `--primary`, `--text` 等，design_guide.md 定义 `--color-primary`, `--color-text`
- 两套命名系统不一致，实际用的是 app.css 中的短命名

#### W7：0.8125rem (13px) 字号大量使用
- 刚好在 13px 下限，但小字体模式下变成 11.4px

#### W8：字体动态缩放机制
- 通过 JS 设置 `document.documentElement.style.fontSize` 覆盖 rem 基准
- `html { font-size: 16px; }` 声明被 JS 覆盖
- 「小」模式 14px root 使所有 rem 值等比缩小 — 这是个功能特性，但使得 11px 变成 9.6px
